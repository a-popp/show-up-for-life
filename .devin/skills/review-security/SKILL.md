name: review-security
description: OWASP ASVS/SSDF security review using the security reviewer subagent
agent: security-reviewer
---

Perform a read-only security review of the requested files, diff, or design. Use OWASP ASVS and lightweight NIST SSDF practices. Focus on secrets, authn/authz, abuse cases, injection, dependency risk, CI/CD integrity, logging, and cloud/email boundaries. Report severity-ranked findings with file/line citations and minimal fixes.
