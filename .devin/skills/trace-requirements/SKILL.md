---
name: trace-requirements
description: Trace a requested feature to design.md requirements before implementation
---

Before implementing the requested product behavior, trace it to `design.md`:

1. Identify relevant requirement/task IDs and quote or cite the smallest necessary excerpts.
2. List acceptance criteria, privacy/safety/accessibility implications, unresolved open decisions, and test implications.
3. Flag conflicts using the priority order in `AGENTS.md`.
4. Ask the user to resolve any blocking open decision before writing code.
Do not implement during this skill.
